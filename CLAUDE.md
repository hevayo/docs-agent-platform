## Agent Manager docs

The `agent-manager/` Doc space documents WSO2 Agent Manager, whose source is [wso2/agent-manager](https://github.com/wso2/agent-manager).

- Use the `docs` skill (`.claude/skills/docs/`) for documentation tasks, alongside `npx @wso2-enterprise/docs help`.
- Verify every technical claim against the `wso2/agent-manager` source, never from memory. `.claude/skills/docs/source.md` says how to find a local checkout and where each feature is implemented.
- `agent-manager/docs/reference/helm-charts/` is generated by `scripts/gen-helm-reference.mjs` from the charts in `wso2/agent-manager`. Don't edit it by hand: fix the chart's `values.schema.json` upstream, then regenerate.
- Write release versions on the main line as `{edition.version}` (`v{edition.version}` for image tags and `amp/v…` refs). In a Markdown link address the Platform doesn't fill variables, so those links keep `v0.0.0-dev` until a Branch cut replaces it by hand.

`init --root-files` replaces this file with the Platform's template: add this section back afterwards.
